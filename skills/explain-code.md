---
name: explain-code
description: Walk through what a piece of code does, step by step, and flag risks
---

Explain the code below (or the file or function named) for someone who knows programming but not this codebase:

- Start with one or two sentences on what it does and why.
- Then walk through it in order, grouping lines that belong together.
- Point out anything surprising: edge cases, error handling gaps, performance traps, security concerns.
- End with how you would test it.

Quote the relevant lines when you refer to them.
